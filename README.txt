Train Coach Management System
=============================

This is a self-contained interactive web project for a Data Structures assignment.

How to run:
1. Extract the ZIP file.
2. Open the Train_Coach_Management_System folder.
3. Double-click index.html to open it in a browser (Chrome or Edge recommended).

Features:
- Add coach at beginning or end
- Insert coach at a chosen position
- Delete by position or coach ID
- Search coach ID
- Reverse coach order
- Visual singly linked-list representation

Note: This is a front-end demonstration. Changes are held in the current page session and are not saved to a database.
